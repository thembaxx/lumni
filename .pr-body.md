## Summary

- 🛡️ **Sentinel Security Fix**
- 🚨 **Severity:** HIGH
- 💡 **Vulnerability:** Insecure Direct Object Reference (IDOR) in `/api/subjects` endpoint
- 🎯 **Impact:** Any unauthenticated attacker could harvest any user's study data (subjects, progress, sessions, streak) by passing a `userId` query parameter
- 🔧 **Fix:** Added server-side session authentication check using `auth.api.getSession()`. The endpoint now verifies the caller is authenticated and only allows access to their own data.
- ✅ **Verification:** `bun run build` passes, TypeScript compiles without errors

## Changes

- Add `auth` import from `@/lib/auth`
- Get session from auth API with request headers via `auth.api.getSession()`
- If no session → return public subjects list only (no user data)
- If `userId` param provided → reject unless it matches session userId
- Return HTTP 403 for unauthorized cross-user access attempts
- Default to authenticated session's userId when no param provided
