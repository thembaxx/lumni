## Why this matters

Lesson progress is currently stored in React state (`useState<Set<string>>` in `lesson-view-client.tsx:38`) — it resets whenever the student navigates away. This means a student who completes 80% of a lesson and accidentally goes back loses everything. Worse, lesson completion never feeds into the competency engine, so the personalization system (quiz difficulty, next-best-action, topic recommendations) has no signal about what students have actually learned through lessons. Closing this loop makes lessons a first-class input to the adaptive learning system.

## Steps

### Step 1: Add `lessonProgress` Dexie table (v33)

In `src/lib/db/schema.ts`, add a new version 33 migration after the existing v32 block.

The table schema:

```ts
// lessonProgress — per-user lesson section completion
"&[userId+lessonId]": string,  // compound primary key
userId: string,
lessonId: string,               // format: "subjectId:topicId:subtopicId"
completedSections: string,      // JSON stringified string[]
completedAt: number,            // timestamp when all sections done
score: number,                  // 0-100, derived from section completion %
updatedAt: number,
```

Also add the TypeScript interface:

```ts
export interface LessonProgressRecord {
  id?: number;
  userId: string;
  lessonId: string;
  completedSections: string; // JSON array of section IDs
  completedAt?: number;
  score: number;
  updatedAt: number;
}
```

Register in the Dexie `version(33).stores({...})` call.
