## Why this matters

The app has quiz, flashcards, lessons, stories, vocabulary, pronunciation, dictionary, and past questions — all as separate features. The TODO.md Wave 3 (lines 777-800) defines 5 integration loops that tie them together. Without these, each feature is useful but the platform doesn't leverage its interconnected data model. This plan implements the 5 integration loops.

## Scope (5 independent integrations)

### Integration 1: Lesson→Past Questions Loop

**Files**:

- `src/lib/integration/service.ts` — already has `suggestQuestionsForLesson()`
- `src/app/[locale]/study/[subjectId]/[topicId]/[subtopicId]/lesson-view-client.tsx` — already shows related questions

**What's missing**: When a student gets a wrong answer on a related question, flag the lesson for review. Use `RetentionService` to schedule lesson re-encounter.

**Steps**:

1. In `lesson-view-client.tsx`, after related questions render, add a "Practice These" button that creates a quiz from the related questions
2. Wire `RetentionService.addRecurrence()` when a related question is answered wrong
3. On the dashboard, surface "Review Lesson: {topic}" in the next-best-action card when a lesson has pending recurrences

### Integration 2: Lesson→Pronunciation Loop

**Files**:

- `src/app/[locale]/study/[subjectId]/[topicId]/[subtopicId]/lesson-view-client.tsx`
- `src/lib/vocabulary/service.ts` (from Plan 002)

**What's missing**: Vocabulary from each lesson feeds into pronunciation practice. Student must pass pronunciation before marking word as "learned."

**Steps**:

1. Add a "Practice Pronunciation" button to the vocabulary section that links to `/pronunciation?text={word}`
2. Track pronunciation scores per word in `vocabularyList` (add `pronunciationScore?: number` field)
3. In the vocabulary section, show pronunciation score badge next to each word
4. A word is only marked "learned" after pronunciation score >= 70%

### Integration 3: Story→Lesson Loop

**Files**:

- `src/lib/stories/service.ts`
- `src/lib/competency-engine/`

**What's missing**: Comprehension scores from stories feed competency for "Reading and Comprehension" topic. Low score suggests simpler story.

**Steps** (mostly done in Plan 003):

1. After comprehension grading, map score to competency (done in Plan 003)
2. Add "Try an Easier Story" link when comprehension score < 50%
3. Add "Reading Streak" widget showing consecutive days with story reading

### Integration 4: Dictionary→Flashcard Loop

**Files**:

- `src/components/vocabulary/word-lookup-popover.tsx` (from Plan 004)
- `src/lib/flashcard-engine/`

**What's missing**: Words saved from dictionary auto-create flashcards.

**Steps**:

1. In `WordLookupPopover`, add "Save & Review" button that saves to vocabulary + creates flashcard
2. The flashcard uses SM-2 spaced repetition for review scheduling
3. In the flashcard session picker, add "Vocabulary Review" session type

### Integration 5: Question Bank→Quiz Engine

**Files**:

- `src/app/[locale]/questions/question-bank-client.tsx`
- `src/hooks/use-quiz.ts`

**What's missing**: "Quiz from past questions" mode — create a quiz using `PastPaperQuestion` records instead of AI-generated questions.

**Steps**:

1. In `question-bank-client.tsx`, add "Quiz Me" button that creates a quiz from selected filters
2. In `useQuiz()` hook, add a `source: "past-questions"` mode that loads `PastPaperQuestion[]` and wraps them as `Question[]`
3. The quiz UI (`QuestionCardInput`, `QuestionCardFeedback`) works unchanged — only the data source changes
