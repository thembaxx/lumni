## Why this matters

The pronunciation page (`/pronunciation`) and dictionary page (`/dictionary`) exist as standalone tools. The lesson view has vocabulary words with a non-functional Mic button. Connecting these creates a seamless "learn word → hear it → practice saying it → look it up" flow that makes the app feel like an integrated learning platform instead of a collection of isolated features.

## Steps

### Step 1: Accept pre-filled text in pronunciation page

Modify `pronunciation-client.tsx` to read `?text=` search param and pre-fill the textarea:
```tsx
const searchParams = useSearchParams();
const prefillText = searchParams.get("text") ?? "";
// In textarea: defaultValue={prefillText}
```

Wrap the component in `<Suspense>` if not already (Next.js 16 requirement for `useSearchParams`).

**Verify**: `npx tsc --noEmit` → exit 0
**Verify**: Navigate to `/pronunciation?text=hello` → textarea pre-filled

- Uses `lookupWord()` from `@/lib/dictionary`
- Uses shadcn `Popover` + `PopoverTrigger` + `PopoverContent`

- Fallback: "No definition found" if empty
