2. Three-Tier Read-Through Caching

Every data request follows the same greedy pattern: try the fastest tier first, fall through to the slowest.

      flowchart TD
        Req["Request Data"] --> T1{"Dexie (IndexedDB)
~1ms"}
        T1 -->|Hit| Return["✅ Return cached"]
        T1 -->|Miss| T2{"Appwrite Cloud
~50-200ms"}
        T2 -->|Hit| T2a["Write to Dexie"] --> Return
        T2 -->|Miss| T3{"Generate
AI / Compute
~2-10s"}
        T3 --> T3a["Write to Appwrite + Dexie"] --> Return

          S["Subjects: 7d"]
          P["Progress: immediate"]
          QP["QuizPacks: 30d"]
        end
