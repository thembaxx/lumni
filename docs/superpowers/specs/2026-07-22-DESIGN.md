# Design System: Lumni Dashboard

## 1. Visual Theme & Atmosphere

A cool-toned, gallery-bright dashboard with Scandi restraint — clinical whitespace, slate-blue accent punctuation, and confident asymmetric grid choreography. The atmosphere sits at Density 5 (daily-app balanced), Variance 7 (offset asymmetry), Motion 6 (fluid spring). Every card earns its elevation; nothing floats without purpose. The overall mood is a well-lit Nordic library: quiet, ordered, but with moments of amber warmth in challenge states.

**Current state assessment:** The dashboard successfully merged 3 tabs into a single scroll, removed ambient noise (ScrollAmbient, NoiseOverlay), and adopted a BentoGrid. However, the execution has **card-radius fragmentation** (5 distinct radius values across 12+ components), a **hero section with easter-egg click handling on the entire element**, and a **color palette that diverges from the documented design spec** (globals.css says slate blue `oklch(55% 0.22 235)` but the dashboard-redesign spec says warm amber).

**Dark mode inversion:** Base becomes near-black (`oklch(10% 0.01 264)`), elevated surfaces brighten (`oklch(20% 0.02 264)`), text inverts to near-white. Accent maintains hue but raises lightness to `oklch(65% 0.22 235)`.

## 3. Typography Rules

- **Display (Headings):** `Geist Variable` — track-tight `tracking-tight`, weight-driven hierarchy through `font-extrabold` / `font-bold`, never through size alone. Scale capped at `--fs-heading-2` (hero) and `--fs-heading-3` (section headings). No `text-4xl` or `text-5xl` raw utilities.
- **Body:** `Geist Variable` — relaxed leading `leading-relaxed` / `leading-snug`, max-width `65ch` on prose blocks. Secondary color for metadata. Minimum `14px` on all viewports.
- **Mono:** `Geist Mono` — exclusively for timestamps, countdown numbers, quiz scores, competency percentages. All numbers in data-dense contexts use `tabular-nums tracking-tight`.
- **Section Headings:** `font-extrabold text-(--fs-heading-3)` with matching icon (16px, `.5rem` gap). Optional `text-muted-foreground` subheading. Never all-caps.
- **Banned:** Inter, generic system fonts, any serif in dashboard contexts. No `uppercase tracking-wider` on section headings — reserved for tiny badges only.

**Current violations:** The focus-timer-card uses `font-semibold text-xs` for the title (should match card-title conventions). The quick-actions buttons use `whitespace-nowrap` stacked icons + labels — acceptable for a toolbar, but the `pill-chip` class pattern needs verification.

## 4. Component Stylings

### Buttons

- **Primary:** Flat, no outer glow. Slate Accent fill (`bg-system-accent`). White text. `rounded-card` (20px). Tactile `active:scale-[0.96]` push feedback with `press-scale` class. Shadow on hover only (`shadow-level-2`), never resting.
- **Secondary / Ghost:** No fill, text in `text-foreground`. `hover:bg-muted/30` with `transition-[background-color]`. Focus ring in accent color.
- **Quick Action Pills:** `pill-chip` — small rounded buttons (`rounded-full`), 32px height, icon + label. `bg-(--material-glass)` ghost state by default, accent fill for primary action. Horizontal scroll container, no visual overflow indicators (user discovers by scroll).
- **Size grid:** `size-sm` (32px), default (40px), `size-lg` (48px). Minimum tap target 44px via `after:absolute after:-inset-2` pattern.

### Cards

- **Resting cards:** `rounded-card` (8px) — radius MUST use consistent class names. All internal items use `rounded-card` (8px). Only Hero and elevated containers use `rounded-card-lg` (24px).
- **Hero card:** `rounded-card-lg` (40px) with `shadow-level-2`. Only card that uses `glass-bento-strong`.
- **Shadow:** `shadow-level-1` for resting cards. Never `shadow-level-3` (reserved for modals). Shadows tinted to background hue (cool-tinted in light mode, warm-tinted in dark).
- **Transition:** `transition-[background-color,box-shadow] duration-200` — never `transition-all`.
- **Border:** `border border-border/30` — 30% opacity whisper border. In dark mode: `dark:border-border/20`.
- **Hover:** `hover:bg-muted/30` — only on actionable cards. Non-interactive cards (stats, word-of-day) get no hover state.
- **High-density override:** In dense layouts, replace nested cards with `border-t border-border` dividers to avoid shadow-on-shadow accumulation.

**Current violations identified:**

- `WordOfDayCard` uses `rounded-2xl` — should use `rounded-card` (same 8px value, correct class name)
- `FocusTimerCard` uses `rounded-xl` — should use `rounded-card`
- `DailyChallengeCard` uses `SpringCard` (good) but icon container uses `rounded-2xl` — should be `rounded-card`
- The `NextBestActionCard` uses `Card` from shadcn — which may have its own radius; verify alignment

### Inputs / Forms

- **Subject Select:** label above input (no floating labels). Focus ring in Slate Accent. Error text below in `text-destructive text-xs`. Helper text optional, grey.
- **Quiz Start Card:** SubjectSelect + Start button pattern is correct. Border `border-system-accent/20` with tinted background `bg-system-accent/5` — acceptable for a CTA card.
- **Generate Plan Form:** Target APS input, daily minutes input. Same label-above pattern.

### Loading States

- **Skeletal loaders:** Match exact card layout dimensions. No generic circular spinners anywhere.
- **Card-level loading:** `Skeleton` components with `rounded-xl` (matching the card's own radius). Shimmer animation via Tailwind's `animate-pulse`.
- **Page-level loading:** `PageSkeleton` from `@/components/ui/skeleton` — replace any mock card-grid skeletons.

**Current violations:** The `stats-row.tsx` loading state renders 2 skeleton cards with `rounded-xl` — but the actual stats cards use the Card component. This mismatch is fine during loading but should match once hydrated.

### Empty States

- **Composed compositions:** "Nothing here yet" with contextual icon, short description, and a CTA to populate the data. Never just text.
- **Study Plan:** `StudyPlanEmpty` with "Generate Plan" CTA — check that it includes a visual (icon or illustration).
- **Weak Topics:** Returns `null` when empty — consider a subtle "All caught up!" state instead of nothing.
- **Quiz Start:** Shows subject picker even before any subjects — acceptable as this is the entry point.

### Error States

- **Card-level:** Inline error message + "Try again" button. `WeakTopicsCard` does this correctly with `refetch()`.
- **No full-page error overlays in dashboard context.**

## 5. Layout Principles

- **Grid-first architecture:** `BentoGrid` with `BentoCell` span options (`full`, `2col`, `2row`) — responsive breakpoints at `sm:grid-cols-2` (tablet) and `lg:grid-cols-3` (desktop), single column below `sm`. Gap pattern: `gap-3 sm:gap-4 lg:gap-5`.
- **No flexbox percentage math.** CSS Grid `col-span` only. No `calc()` hacks.
- **Max-width containment:** `PageContainer` owns `max-w-*` and `px-*`. Components never declare their own page-level widths.
- **Hero section:** Left-aligned greeting + countdown, with `YearRingProgress` offset to the right side. No center alignment — variance exceeds 4 so centered layout is banned.
- **The generic "3 equal cards horizontally" pattern is banned.** The current StatsRow (streak fire + achievements + progress chart in a 2-column grid) avoids this correctly by using a `grid grid-cols-1 sm:grid-cols-2` split.
- **No overlapping elements.** Every card occupies its own clean spatial zone. The hero's decorative blurred circles use `pointer-events-none` and `absolute` positioning — acceptable for ambient depth.
- **Quick Actions row:** Horizontal scroll container, overflow hidden on desktop (partial reveal signals more actions). No scroll arrows or bouncing chevrons.
- **Full-height sections:** `min-h-[100dvh]` — never `h-screen` (iOS Safari catastrophic jump). The dashboard content uses `h-full` inside a flex column — verify this resolves to `min-h-[100dvh]` at the page level.

## 6. Motion & Interaction

- **Spring Physics default:** `stiffness: 100, damping: 20` — weighty, premium feel. Implemented via `press-scale` class (`active:scale-[0.96]` with CSS transition). No linear easing in interactive states.
- **Staggered cascade reveals:** `StaggerProvider` with `baseDelay={0.02}` wraps all dashboard sections. Each section animates in via `animate-section-reveal`. Gaps between sections (8/10/12) create natural waterfall pacing.
- **Perpetual micro-interactions:**
  - **Daily Challenge streak badge:** `animate-float-bob` on milestone emoji with `0.15s` delay — correct.
  - **Amber glow pulse:** `animate-halo-pulse` on challenge card icon background — correct.
  - **Hero accent gradient:** `transition-opacity duration-500` on hover — correct.
  - **Countdown number:** `tabular-nums tracking-tighter` with `aria-live="polite"` — correct.
  - **Gap:** No shimmer/float on the streak fire icon, no subtle pulse on the year ring progress.
- **Performance:** Animate exclusively via `transform` and `opacity`. The `press-scale` class uses `transform: scale(0.96)` — correct. Never animate `top`, `left`, `width`, `height`.
- **Reduced motion:** Wrap spring animations in `@media (prefers-reduced-motion: reduce)` fallback. The codebase has a `motion-safe` custom variant — use it.
- **Isolated Client Components:** FocusTimerCard is already dynamic-imported with `ssr: false` — correct. No other dashboard component is CPU-heavy enough to need isolation.

## 7. Responsive Rules

- **Mobile-first collapse (< 768px):** All grids collapse to single column. Hero content stacks vertically (YearRingProgress moves below the greeting on mobile via `sm:flex-row`).
- **No horizontal scroll on mobile:** QuickActions uses horizontal scroll — acceptable for a toolbar pattern, but ensure the container has no visible scrollbar (`scrollbar-hide`).
- **Typography scaling:** Body text never below `14px`. Headlines scale via responsive utility classes (not `clamp()` in the current implementation — `text-5xl md:text-6xl` pattern — verify this works at all intermediate viewports).
- **Touch targets:** All interactive elements minimum `44px` tap target. Button pattern uses `after:absolute after:-inset-2` for guaranteed hit area. Icon-only buttons (focus timer controls) use `size-8` with the `after:-inset-2` expansion — this yields 48px effective tap target. Correct.
- **Image behavior:** No inline typography images in the current dashboard — acceptably, as this is a productivity tool, not a landing page.
- **Spacing:** Section gaps reduce proportionally — `gap-8 sm:gap-10 lg:gap-12`. Hero padding `px-5 py-5 sm:px-6 sm:py-6`.

| --------------- | -------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------ |

| Daily Challenge | `SpringCard` wrapper             | `animate-halo-pulse`, `animate-float-bob` | Correct — most polished card                                             |
| Weak Topics     | No spring (shadcn Card)          | No micro-interaction                      | Add `press-scale` on practice buttons (exists already — verify it fires) |
| Word of Day     | No spring (`rounded-2xl` Link)   | No micro-interaction                      | Add hover scale on card                                                  |
| Quick Actions   | No spring                        | No micro-interaction                      | Acceptable for toolbar pattern                                           |
| Focus Timer     | No spring (shadcn Card)          | No micro-interaction                      | Add subtle pulse on running state                                        |
| Stats Row       | No spring (shadcn Card)          | No micro-interaction                      | Acceptable for data display                                              |
| Study Plan      | No spring (shadcn Card)          | No micro-interaction                      | Add on session items only                                                |
