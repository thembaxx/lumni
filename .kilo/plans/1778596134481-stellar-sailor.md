# Plan: Add Markdown and KaTeX Support to StudyTopicCard

## Problem Analysis

The `StudyTopicCard` component in `src/components/study/study-topic-card.tsx` renders the topic summary as plain text, splitting words for word-by-word highlighting during TTS playback (lines 131-145). This approach:

1. Does NOT support markdown formatting (bold, italic, lists, code blocks, etc.)
2. Does NOT support KaTeX mathematical equations (`$...$` or `$$...$$` syntax)
3. Cannot display the rich content that other similar components support

## Evidence

- `LessonCard` (src/components/lesson/lesson-card.tsx:82, 150) uses `MarkdownRenderer` to render summary
- `Flashcard` component uses `MarkdownRenderer` for card content
- The project has a mature `MarkdownRenderer` component (src/components/markdown-renderer.tsx) with:
  - `remark-math` and `rehype-katex` for equation rendering
  - Support for GFM (tables, strikethrough, etc.)
  - Math detection for STEM subjects

## Solution

Replace the manual word-splitting text rendering with `MarkdownRenderer` while preserving the TTS word-highlighting functionality.

### Implementation Steps

1. **Replace plain text rendering with MarkdownRenderer**
   - Import `MarkdownRenderer` from `@/components/markdown-renderer`
   - Change the summary display (lines 131-145) to use `<MarkdownRenderer>`

2. **Handle word highlighting separately from rendering**
   - Keep the word array for TTS highlighting (used by `ListenToLesson`)
   - The `ListenToLesson` component receives raw text for word boundary detection
   - Word highlighting can be maintained at the paragraph level if needed

3. **Add subject prop for proper math styling**
   - Pass `subject` prop from topic data to `MarkdownRenderer`
   - This enables proper KaTeX styling for math subjects

### Key Considerations

- The word-highlighting during TTS playback uses `onWordIndexChange` from `ListenToLesson`
- The current implementation highlights individual words in the summary text
- If word highlighting is still required, we may need to:
  - Strip markdown for the TTS word counting (already passed raw text)
  - OR accept that highlighting won't work perfectly with markdown content

### Files to Modify

- `src/components/study/study-topic-card.tsx` - Main change

### Alternative Approach (if word highlighting must be preserved)

Create a custom component that:
1. Renders markdown content normally
2. Wraps words in spans for highlighting (complex and fragile)
3. OR accepts that the highlighting feature works on the raw text only
