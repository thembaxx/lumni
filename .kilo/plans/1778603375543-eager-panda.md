# Fix Bottom Nav Transparent Background

## Problem

The bottom navigation bar appears transparent in both light and dark themes due to incorrect CSS variable usage and misplaced separator border.

## Root Cause Analysis

### 1. Wrong CSS Variable

- **Current:** `bg-[--system-surface]`
- **Expected per iOS spec:** `bg-[--system-background]`

The CSS variable values are:

- Light: `--system-surface: oklch(100% 0 0)` (white) vs `--system-background: oklch(100% 0 0)` (also white - same value)
- Dark: `--system-surface: oklch(13% 0.002 264°)` (dark gray) vs `--system-background: oklch(8% 0 0)` (near black)

The difference in dark mode could cause visibility issues with content behind the nav - the surface is a lighter gray than the background, creating a visual mismatch.

### 2. Misplaced Separator Border

- **Current:** Uses `ios-separator` class which adds `border-bottom: 0.33px solid var(--system-separator)`
- **Expected per iOS spec (line 140):** Top hairline border: `0.33px solid var(--system-separator)`

The border should be on top, not bottom, so nav items don't blend with the border.

## Proposed Fix

Change line 142 in `src/components/navigation/bottom-nav.tsx`:

**From:**

```tsx
<nav className="fixed bottom-0 left-0 right-0 z-50 h-[49px] bg-[--system-surface] ios-separator md:hidden pb-safe">
```

**To:**

```tsx
<nav className="fixed bottom-0 left-0 right-0 z-50 h-[49px] bg-[--system-background] border-t border-[--system-separator] md:hidden pb-safe">
```

Changes:

1. Change `bg-[--system-surface]` to `bg-[--system-background]` (per iOS spec)
2. Replace `ios-separator` (bottom border) with `border-t border-[--system-separator]` (top border)
