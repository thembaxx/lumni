## Implementation Steps

1. **Create IconMapping utility** - Map animation names to Phosphor icons with animation presets
2. **Update celebration components** - Set `useLottie={false}` by default
3. **Replace LottieWrapper usages** - With animated Phosphor icons using framer-motion
4. **Delete lottie directory** - Remove all lottie-related files
5. **Remove animation files** - Delete public/animations/*.lottie
6. **Update package.json** - Remove @lottiefiles/dotlottie-react dependency
7. **Update scripts** - Remove lottie generation scripts

## Animation Presets (framer-motion)

```tsx
const iconAnimations = {
  spin: { rotate: 360, transition: { duration: 1, repeat: Infinity, ease: "linear" } },
  pulse: { scale: [1, 1.1, 1], transition: { duration: 1.5, repeat: Infinity } },
  bounce: { y: [0, -10, 0], transition: { duration: 0.6, repeat: Infinity } },
  shake: { x: [-5, 5, -5, 5, 0], transition: { duration: 0.4 } },
  scale: { scale: [0, 1.2, 1], transition: { duration: 0.3 } },
};
```
